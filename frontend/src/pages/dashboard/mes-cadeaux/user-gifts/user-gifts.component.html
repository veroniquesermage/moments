🎁 Mes cadeaux

Voici vos désirs soigneusement ordonnés par priorité. Même la convoitise mérite un certain ordre.

Utilisez la poignée ↕️ pour réorganiser vos souhaits selon l'urgence du moment. Ici on aime les choses accomplies, il vous faut valider vos changement de priorités.
Cliquez sur un cadeau pour consulter son détail, le perfectionner ou, si le cœur vous en dit, l'effacer de vos préoccupations.

Chaque ligne commence par des boutons pour modifier la priorité : utilisez Tab pour les afficher, puis les activer avec Entrée ou Espace.
